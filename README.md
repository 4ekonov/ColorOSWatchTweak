# ColorOS Clock (v0.1)

Твик для джейлбрейка iOS 15–17: часы на экране блокировки в стиле ColorOS.

## Что есть в v0.1

- 3 варианта часов:
  1. растянутые, виджеты снизу
  2. растянутые, виджеты сбоку
  3. растянутые слева экрана
- Настройки (Настройки → ColorOS Clock): отступы со всех сторон, размер, ширина, высота,
  прозрачность часов, сдвиг по X/Y, 24-часовой формат.
- Виджеты: «Дата», «Батарея», «Заметка» + прозрачность, скругление и размер карточек.
- Отдельные отступы сверху и снизу для списка уведомлений.
- Живое применение настроек (без респринга, кроме скрытия штатных часов).

## Как собрать deb на GitHub (без компьютера с Theos)

1. Зарегистрируйся / войди на github.com и нажми **New repository**
   (название любое, например `ColorOSClock`, видимость любая).
2. Загрузи в репозиторий **всё содержимое** этой папки, включая скрытую папку `.github`
   (на сайте: **Add file → Upload files**; на телефоне проще через приложение GitHub
   или через десктопную версию сайта; папку `.github/workflows/build.yml` нужно сохранить
   с тем же путём).
3. Открой вкладку **Actions**. Если GitHub просит — нажми **I understand my workflows, enable them**.
4. Сборка стартует сама после загрузки. Либо: **Actions → Build deb → Run workflow**.
5. Когда сборка станет зелёной, открой её и внизу в **Artifacts** скачай `ColorOSClock-deb`.
   Внутри два файла:
   - `..._iphoneos-arm.deb` — rootful (unc0ver, checkra1n, palera1n rootful)
   - `..._iphoneos-arm64.deb` — rootless (Dopamine, palera1n rootless)
6. Установи deb через Filza / Sileo / `dpkg -i`, потом respring.

### Релиз с готовыми deb

Создай тег `v0.1.0` (в GitHub: **Releases → Draft a new release → Choose a tag → Create new tag**).
Workflow сам прикрепит deb к релизу.

## Если сборка упала

Открой упавший шаг в Actions, скопируй текст ошибки и пришли мне — исправлю.

## Что дальше (v0.2)

- Точное совпадение геометрии, шрифта и виджетов с ColorOS (нужны скриншоты оригинала).
- Виджет погоды, календаря, шагов.

## v0.7 — малые часы при уведомлениях

- Если на экране блокировки есть хоть одно уведомление, любой из 3 вариантов часов плавно превращается в малые часы
  (цифры слева сверху, дата справа, ряд виджетов под ними) — у каждого варианта своя траектория.
- Когда историю уведомлений вытягиваешь пальцем, сжатие идёт вместе с пальцем (туда-сюда — анимация туда-сюда).
  В остальных случаях — мягкая анимация (~0.6 с). Скорость, размер малых часов и путь сжатия — в настройках.
- Виджеты теперь без размытия: просто полупрозрачная заливка (прозрачность — в настройках виджетов).
- Если часы не сжимаются: включи в настройках «Отладочную строку» — вверху покажет, сколько ячеек уведомлений найдено.

## v0.8 — размер и положение на экране блокировки

- Настройки «Размер / Ширина / Высота» убраны. Долгое нажатие на самих часах (экран блокировки) открывает редактор:
  тяни рамку — двигаешь часы, тяни уголок — меняешь размер («Пропорции: выкл» — тянуть ширину и высоту отдельно),
  «Готово» сохраняет, «Отмена» возвращает как было, «Сбросить» — стандартный размер и положение.
- Отступы и сдвиги остаются в настройках (редактор меняет те же значения сдвига).
- Анимация сжатия стала в 1,5 раза медленнее; в настройках — слайдер «Скорость анимации».

## v0.9.1 — установка

## v0.10 — виджеты в редакторе, малые часы с «Нет прошлых уведомлений»

- Часы остаются малыми, пока на экране есть надпись списка («Нет прошлых уведомлений»), как и при обычных уведомлениях.
- Редактор (долгое нажатие на часах): виджеты двигаются отдельно от часов, красный «−» убирает виджет, «+ Виджет» добавляет
  (будильник, погода, батарея, дата, заметка). Размер виджетов остался в настройках.
- Переключатели отдельных виджетов из настроек убраны. Прежний выбор подхватывается автоматически.
- Пока редактор открыт, экран не гаснет (если iOS позволяет — используется внутренняя блокировка автоблокировки).
